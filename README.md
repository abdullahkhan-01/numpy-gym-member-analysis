# Gym Member Analysis using NumPy

A beginner-friendly data analysis project built using Python and NumPy.

## Dataset

The dataset contains information about 12 gym members.

### Columns

| Column | Description |
|---|---|
| Member ID | Unique ID of each member |
| Age | Age of the member |
| Weight | Weight in kilograms |
| Workouts per Month | Number of workouts per month |
| Average Workout Hours | Average hours spent working out |

## Analysis Performed

1. Find the average age and average workout hours.
2. Find the member with the highest number of workouts per month.
3. Find members with 7 or more workouts per month.
4. Find members whose age is greater than 30 and workout hours are greater than 8.
5. Find the heaviest member among those who work out for 8 or more hours.
6. Find the member with the lowest workout hours among members older than 25 who work out at least 6 times per month.

## NumPy Concepts Used

- NumPy arrays
- Array slicing
- `np.mean()`
- `np.argmax()`
- `np.argmin()`
- Boolean indexing
- Multiple conditions using `&`
- Filtering and analyzing data

## Purpose

This project was created to practice basic NumPy data analysis and learn how to convert real-world questions into NumPy operations.
